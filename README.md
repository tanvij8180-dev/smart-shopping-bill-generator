# Smart Shopping Bill Generator 🧾

## 📌 Project Overview

The **Smart Shopping Bill Generator** is a Python-based project that helps generate a shopping bill automatically. It allows the user to enter item details such as item name, quantity, and price, and then calculates the total bill.

The project is designed to make bill calculation simple, fast, and accurate.

## 🎯 Project Objective

The main objective of this project is to create a simple and user-friendly billing system using Python.

It helps in:

* Adding multiple shopping items
* Calculating item-wise totals
* Calculating the subtotal
* Applying discount
* Calculating GST
* Generating the final bill amount

## ⚙️ How the Project Works

1. The user enters the item name.
2. The user enters the quantity.
3. The user enters the price of the item.
4. The program calculates the amount for each item.
5. The subtotal is calculated.
6. Discount and GST are calculated.
7. The final bill amount is displayed.

 ## ▶️ How to Run

### Step 1
Make sure Python is installed on your computer.

### Step 2
Open the project in Python IDLE or any Python editor.

### Step 3
Open the `main.py` file.

### Step 4
Run the program.

### Step 5
Enter the required item details when asked.

The program will calculate and display the final shopping bill.
